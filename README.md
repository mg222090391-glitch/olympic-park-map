# 올림픽공원 편의시설 지도

> 휠체어·유아차·어르신·임산부·공연 관람객이 **내 상황에 맞는 화장실·쉼터·충전기·엘리베이터·AED·병원·약국**을 찾고, **날씨에 맞춰 걷는 길**로 안내받는 웹 지도입니다.
> KSPO(국민체육진흥공단) 공공데이터 활용 팀 프로젝트

**🔗 바로 써 보기: https://mg222090391-glitch.github.io/olympic-park-map/**

<img src="assets/qr-site.svg" width="160" alt="사이트 주소 QR코드">

휴대폰 카메라로 QR코드를 찍으면 바로 열려요. 설치나 로그인은 필요 없어요.

## 어떤 문제를 풀었나요

올림픽공원은 넓고, 공연·경기가 있는 날에는 사람이 많이 몰립니다.
휠체어를 탄 사람은 *장애인 칸이 있는* 화장실을, 유아차를 끄는 보호자는 *기저귀 교환대가 있는* 화장실과 *계단 없는 길*을,
더운 날 어르신과 함께 온 가족은 *운영 중인 무더위쉼터*를 찾아야 합니다.
그런데 이런 정보는 여러 기관의 공공데이터에 흩어져 있습니다. 이 서비스는 그 데이터를 한 지도에 모아 **"내 상황 → 가고 싶은 곳 → 날씨 맞춤 길안내"** 세 단계로 보여 줍니다.

### 공유 주소 형식

주소 뒤 `#`에 영문 소문자와 하이픈(-)만 써요.

```
https://mg222090391-glitch.github.io/olympic-park-map/#wheelchair-toilet
https://mg222090391-glitch.github.io/olympic-park-map/#stroller-elderly-rest-from-peacegate
```

| 낱말 | 뜻 | 쓸 수 있는 값 |
|---|---|---|
| 상황(여러 개) | 고른 상황 | `wheelchair` `stroller` `elderly` `pregnant` `concert` |
| 가고 싶은 곳(하나) | 목적지 | `toilet` `rest` `shop` `water` `charger` `elevator` `aed` `transit` `medical` |
| `from-…` (선택) | 출발지 버튼 | `olympicstation` `mongchonstation` `hanseongstation` `peacegate` `southparking` `northgate` |

내 위치(GPS)와 지도에서 직접 고른 출발지는 주소에 담지 않아요. 시연용 예시 날씨는 `?weather=sample`(체감 33.5°)로 열어요.

## 기술 구성

- **화면**: HTML · CSS · 순수 JavaScript (빌드 도구 없음, GitHub Pages로 배포)
- **지도**: MapLibre GL JS (3D), three.js (찾아가기 1인칭 모드)
- **그래프**: Chart.js
- **날씨 중계 서버**: Cloudflare Workers (`worker/worker.js`)
- **길찾기**: 걷는 길 그래프 + A* 알고리즘(길안내) · 다익스트라(추천 목록 거리를 한 번에) — 브라우저에서 계산
- **음성**: Web Speech API (브라우저 내장)
- **QR코드**: 직접 만든 생성기 `qr.js` (외부 라이브러리 없음)

## 직접 실행해 보기

```bash
git clone https://github.com/mg222090391-glitch/olympic-park-map.git
cd olympic-park-map
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 (예시 날씨: http://localhost:8000/?weather=sample)
```

## 한계와 주의할 점

- KSPO 편의시설 정보는 **2021년에 한 번 수집**된 데이터라 지금과 다를 수 있어요.
- 길안내·추천 목록·팝업 거리는 모두 OpenStreetMap 걷는 길 기준이고, **경사·공사·통제 구간은 반영되지 않아요**. 길 데이터로 이어지지 않는 곳만 직선거리로 계산해 '직선거리 기준'이라고 표시해요.
- 화장실 운영시간이 '정시'로 적힌 곳은 24곳 중 2곳뿐이라, '운영시간 확인된 곳만'을 켜면 결과가 적어요.
- AED 데이터 중 **설치 위치 설명과 좌표가 맞지 않는 7대**(여러 건물이 같은 좌표인 6대, '체조경기장 지하1층'인데 약 900m 떨어진 1대)는 응급 화면의 '가까운 AED'에서 빼고 목록에서는 뒤로 보내요.
- 응급 화면의 위치 설명은 출입문·역·경기장 등 기준점 24곳과의 방향·거리로 만든 문장이라, 정확한 주소가 아니에요. 좌표를 함께 알려 주세요.
- 도보 시간은 걸음 속도를 **가정**한 값이에요(일반 분당 67m, 휠체어·유아차·오래 못 걷는 동행·임산부 분당 50m).
- 버스 노선은 OpenStreetMap 기준이라 빠지거나 바뀐 노선이 있을 수 있어요.
- **택시 타기 좋은 곳**은 공식 승강장 데이터가 없어서, 큰길과 바로 이어지는 출입구 4곳을 추천한 거예요.
- 한파쉼터는 운영시간 정보가 없어 '운영 확인 필요'로 보여 줘요. 공휴일 운영 여부는 반영하지 않았어요.
- 음성 안내 목소리는 브라우저·기기마다 달라요.
- 약국·보건소 운영시간은 **2026-11-26에 E-GEN에서 받은 값**이라 바뀌었을 수 있어요. **공휴일 달력은 반영하지 않아요**(공휴일 운영시간은 팝업에만 보여 줘요). 방문 전에 전화로 확인하라고 안내해요.
- 응급실은 24시간 운영으로만 표시하고, **병상·진료과 같은 실시간 상황은 알 수 없어요**. 전화번호는 병원 대표번호예요. 응급실은 공원 밖 1~3km라 거리를 **직선거리**로 비교해요. 위급하면 119를 먼저 누르도록 안내해요.
- 보건소는 진료·예방접종 등 업무가 정해져 있어 일반 병원처럼 진료받지 못할 수 있어요.
- 병원·의원의 **진료과목은 병원이 E-GEN에 등록한 표시 과목**이라, 내과 의원이 소아청소년과·피부과 등을 함께 올려 둔 경우가 많아요. 그 과 전문의가 있는지는 전화로 확인하라고 안내해요. 공원에서 1.5km 밖 병원(응급실 제외)은 넣지 않았어요.
